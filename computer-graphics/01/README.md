# 1.
    Это процесс преобразования геометрического объекта в набор дискретных пискелей растра. 
# 2.
    Чтобы за один шаг не пройти больше одного пикселя по самой длинной оси. Если взять меньшее число шагов, линия будет с разрывами. Если взять большее - появятся лишние пиксели на одном месте.
# 3.
    Потому что после прибавления дробных приращений координаты становятся вещественными, а пиксель имеет целочисленные координаты.
# 4.
    Деление на 0 невозможен, поэтому в функции есть проверка: рисуется один пискель в точке и происходит выход.
# 5.    
    -Выполняет деление на каждом отрезке.
    -Требует округления на каждом шаге.
    -Использует вещественные числа.
