    А:
     Поворот:
       x' = 2*cos(90) - 1*sin(90) = -1
       y' = 2*sin(90) + 1*cos(90) = 2 
     Перенос:
       x'' = -1 + 3 = 2
       y'' = 2 + 0 = 2
     Итог:
       (2,2)
    Б:
     Перенос:
      x'' = 2 + 3 = 5
      y'' = 1 + 0 = 1
     Поворот:
      x'' = 5*cos(90) - 1sin(90) = 0  - 1 = -1
      y'' = 5*sin(90) + 1*cos(90) = 5 + 0 = 5
     Итог:
      (-1,5)
