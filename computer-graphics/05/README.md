# 6.
    Прямоугольник - залит внутри
    Треугольник - залит внутри
    Выпуклый - залит внутри
    Невыпуклый - залит внутри
    Горизонтальное ребро - залит внутри
    Строка через вершину - работает
    Flood fill, старт внутри - залит только внутри
    Flood Fill, старт снаружи - залита область снаружи, внутри не залито 
    Незамкнутный контур - закрашено все, кроме контура
