# 1.
    Открыть файл index.html. 
# 2.
    Используется JSONPlaceholder: https://jsonplaceholder.typicode.com/posts
# 3.
    Реализованы следующие HTTP-методы:
        GET - запускает список публикаций
        POST - создает новую публикацию
        PATCH -изменяет заголовок и текст существующей
        DELETE - удаляет публикацию
# 4.
    Все состояние храниться в объекте state, где
        post - массив публикаций, isLoading - первичная загрузка списка, isSaving - сохранение,
        deletingId - id публикации, которая сейчас удаляется, error - ошибка загрузки, filter - строка списка
        editingId - число редактирований, изначально пустое
# 5.
    response.ok === false - выбрасывается Error с кодом статуса(Например, HTTP 404)
    ошибка загрузки списка попадает в state.error
    ошибка сохранения 
    ошибка удаления
# 6.
    После POST:
        Сервер возращает созданный объект с новым id.
        Объект добавляется в начало state.posts
        Форма очищается
        Вызывается render - новая карточка появляется сверху
    После PATCH:
        Сервер возращает обновленный объект
        В state.posts находим запись по id и заменяем её объединённым объектом
        Форма очищается, editinId сбрасывается в null
        render перерисовывает карточку с новыми данными
    После DELETE:
        Сервер подтверждает удаление 
        Только после этого из state.posts удаляется запись
        render убирает карточку из DOM        
# 7.
    JSONPlaceholder — учебный сервис. Он принимает POST,PATCH и DELETE и возвращает правдоподобные ответы, но реально не сохраняет изменения в базе данных.
